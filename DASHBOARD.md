# HRMS & ERP Dashboard Overview

## Structure
The dashboard serves as the central hub for the HRMS Assistant. It adheres to a modern, responsive design with a persistent sidebar and top navigation bar.

## Key Components

### 1. Main Layout
- **Sidebar**: Collapsible navigation menu containing links to all modules (Recruitment, Employees, Leave, Training, Payroll).
- **Top Bar**: Contains the application title, user profile dropdown, and global notifications.
- **Main Content**: The dynamic area where module pages are rendered.

### 2. Dashboard Page
- **Quick Stats**: Cards showing summary data (e.g., "Open Positions", "Headcount", "Pending Approvals").
- **Recent Activity**: A list of recent system actions.
- **Quick Actions**: Shortcuts to common tasks like "Add Employee" or "Approve Leave".

## AI Integration
- The AI Assistant widget will float on the bottom right, accessible from any page, allowing voice or text commands to navigate or perform actions within the dashboard.
